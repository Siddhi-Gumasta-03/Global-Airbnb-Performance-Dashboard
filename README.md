# Global Airbnb Performance Dashboard
## Project Overview
An interactive Power BI dashboard developed to analyze Airbnb performance across multiple cities and understand trends in listings, hosts, pricing, reviews property types, and customer raings.
The dashboard provides an overview of the Airbnb market and helps identify patterns in listings growth, city-level performance, pricing, and customer satisfaction.
---
## Objectives
-Analyze Airbnb listings across different cities.
-Understand listings and host distribution
-Analyze pricing across different room/property types
-Compare market performance across cities
-Analyze customer ratings and review trends
-Identify listings lifecycle and growth patterns
-Present key insights through interactive Power BI dashboards
